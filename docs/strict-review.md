# 代码严格复核

审查日期：2026-10-28。重点逐链复核直播播放与聊天、账号过滤、设置、页面通信、礼物与 SC、窗口资源释放；其余清理文件核对非注释代码及模板编译结果。全仓库运行静态检查，但不声称逐行审查了所有第三方依赖或覆盖了全部运行环境。

## 已修复的问题

| 级别 | 触发条件与影响 | 处理 |
| --- | --- | --- |
| P1 | 聊天输入连续积压，或多层压缩包累计展开；原有限制无法覆盖整条解码链 | 输入与展开共享 8 MiB 预算，每批最多 4096 包；连接待解码队列最多 64 帧、8 MiB。Brotli 首块与后续元块均检查输出上限 |
| P1 | 过滤候选被挤出后，其身份检查仍在执行；只限制数组长度不能限制在途任务 | 候选队列、在途过滤检查各限制为 256；丢弃旧候选，保留最新候选与输出顺序；及时清理查询超时器 |
| P2 | 首次登录态请求尚未结束时切换画质，刷新版本号使聊天初始化被丢弃 | 同房间刷新保留初始化；切房、切账号、受限状态和卸载仍使旧结果失效 |
| P2 | 账号切换后的登录态读取失败，聊天停留在等待规则状态 | 展示可重试错误，通过重新获取聊天认证恢复 |
| P2 | 画中画关闭时直接访问跨域 iframe 文档；窗口 pagehide 重入关闭，或异步开窗晚于组件卸载 | 复用媒体释放函数，关闭去重，卸载时移除监听并关闭窗口；晚到窗口立即释放 |
| P2 | 通知抽屉清理时手动删除 Vue 管理的 iframe，并调用不能关闭嵌入窗口的 Window.close | 在隐藏前释放媒体，让 Vue 管理节点移除，保留跨域导航释放 |
| P2 | 直播搜索“查看更多主播”只写日志，点击无作用 | 补齐子页、结果面板和根筛选器事件，复用分页重置与 URL 更新 |
| P3 | 礼物模态框内按 D 会更改底层弹幕设置；输入法组合状态未单独处理 | 所有已打开的模态框及组合输入均拦住快捷键 |
| P3 | 拖动到未缓存区时，无障碍文字仍可能宣称正在直播 | 播报拖动预览及不可用状态；删除透明进度输入的无效样式 |
| P3 | 异常等级字段为布尔值、数组或空白字符串时可能被强制转换成等级 | 按未知身份规则处理，不误判为 LV0/LV1 |

P1 表示需优先修复的资源边界问题，不代表已证实存在可由任意站外攻击者利用的漏洞。Brotli 输出预算不等于整个进程的内存硬上限，解码器仍需要临时工作内存。

## 安全结论与剩余事项

复核的代码及数据流中，未发现病毒植入、挖矿、键盘记录、下载执行远程脚本或向未知目标外传凭据的行为。敏感能力仍限于现有 B 站请求、Cookie 与页面适配用途；本轮未扩大权限。此结论是有范围的代码审查，不是“绝对无毒”的保证。

本轮锁文件未变。当天注册表审计结果：生产依赖 0 条；完整工具链 159 条，包括 low 11、moderate 53、high 89、critical 6。critical 涉及 basic-ftp、shell-quote、tar、Vitest、tinypool 的开发或发布依赖路径；未强制跨大版本更换整套工具链。本次实际打包的 27 个依赖版本与全部公告交叉检查，未命中剩余告警。详细数据流及历史产物记录见[安全审查](security-review.md)。

扫描安装包 10 个 JavaScript 文件：直接 eval 未命中；3 处 `new Function()`、5 处 `Function()` 均为依赖中获取全局对象的 `return this` 兼容分支，保留原有环境判断或异常回退，未放宽 CSP。Vue 模板编译器对应的构造函数已移除。此次同时统计有无 new 的调用，上轮仅统计构造调用，两组总数不能直接比较。这些静态检查不等于覆盖所有动态路径。

仍需区分以下边界：

- 未检验真实直播 CDN、登录风控、浏览器事件时序、跨域画中画视觉效果及真实礼物/SC 支付。没有使用浏览器，没有下载 PotPlayer 文件。
- 固定 10 分钟时间轴只是显示窗口，实际回看取决于媒体缓存；未接入服务器时移，不能保证进入房间前已有完整历史。
- 高频消息超过边界时会舍弃旧候选，优先保持页面响应；不承诺保存全部聊天历史。
- 上游搜索分类数量仍未从各结果页汇总；这属于待完善展示，不能据本轮检查声称全仓库所有产品分支均完整实现。
