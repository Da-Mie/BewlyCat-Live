# 来源与许可

- [BewlyCat](https://github.com/keleus/BewlyCat)：本分支的直接基础，上游作者与历史贡献保留。
- [BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)：原始项目。
- [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)：直播模块分层与接口处理的参考。
- [vitesse-webext](https://github.com/antfu/vitesse-webext)：扩展模板。
- [UserScripts/bilibiliHome](https://github.com/indefined/UserScripts/tree/master/bilibiliHome)、[bilibili-app-recommend](https://github.com/magicdawn/bilibili-app-recommend)：访问密钥处理参考。
- [Bilibili-Evolved](https://github.com/the1812/Bilibili-Evolved)、[bilibili-API-collect](https://github.com/SocialSisterYi/bilibili-API-collect)：相关实现与接口资料。
- [MingCute](https://github.com/mingcute-design/mingcute-icons)：界面图标；许可副本见 [MingCute-LICENSE.txt](../assets/licenses/MingCute-LICENSE.txt)。
