# BewlyCat Live 1.8.2

基于 BewlyCat 1.8.2 的个人维护分支，以预发布形式提供 Chrome / Edge 扩展。

## 本次调整

- 选中直播画面时显示底栏，不再出现外框；播放中闲置 2.5 秒自动淡出，移动鼠标或操作快捷键时恢复。暂停、拖动和键盘操作底栏时保留控件。
- 进度条横贯播放器底部，正常直播时保持在末端；拖动时固定刻度并预览位置，松开后跳转，避免缓冲更新打断拖动。增加落后时长、可回看时长和“回到直播”。
- 统一底栏按钮、圆角与图标，调整全屏和画中画入口，为弹幕及 SC 留出空间，保留 B 站原生弹幕开关图形。
- HLS 按分片码率调整历史缓冲，目标上限 15 分钟并保留内存余量；FLV 使用约 2–3 分钟的回收窗口。实际可回看时长受线路、码率和浏览器缓存限制。

## 已有调整

- 直播画面单击选中，双击播放 / 暂停；左右方向键在可用缓冲范围内前后移动 5 秒，上下方向键调节音量 5%。
- 播放器控制条支持播放、静音、音量、缓冲进度和画中画，保留全屏与音量记忆；输入框和弹窗不占用播放器快捷键。
- README 恢复完整上游介绍，个人分支简介与下载入口位于顶部。

## 新增

- 评论、视频卡片、直播消息的账号等级过滤，普通 LV6 与硬核会员可分别选择。
- 渲染前过滤，无屏蔽占位、数量或记录，保留原始评论关系、分页与折叠状态。
- 默认使用统一布局的新版直播间，支持清晰度、线路、聊天、屏幕弹幕、全屏、隐藏顶栏与观看设置记忆。
- 增加普通礼物与 SC 发送、SC 悬浮卡片、可独立关闭的礼物动效，以及主播背景图。
- 继承 B 站账号的原版直播屏蔽词与屏蔽用户；弹幕开关支持 D 键。

## 整理与修复

- 处理账号 / 房间切换时的过期查询和发送结果，统一缓存容量限制与卸载清理。
- 整理设置分类导航、发送按钮文字、弹窗动效与观看界面的文案和圆角。
- 直播样式按入口提取，播放与解码库按需载入。
- 保留 B 站原生弹幕开关图形，补齐直播依赖及图形来源说明。

## 安装与边界

下载 extension.zip，解压后在浏览器扩展页通过“加载已解压的扩展程序”安装。更新后重新加载扩展并刷新 B 站标签页。

回看仅限本次观看已缓冲的画面，无法保证获取进入直播间前的内容；刷新、切换清晰度或线路后重新积累。HLS 的 15 分钟是配置上限，并非每条线路都能保留这么久。回看画面时聊天与 SC 继续显示当前直播消息。

普通视频弹幕不提供等级过滤。普通礼物与 SC 需要登录并确认金额后发送；背包、盲盒、大航海、充值与活动功能仍通过原版直播间使用。真实支付及审核链路尚未实机验收。此版本未上架浏览器扩展商店。完整实机回归尚未完成，请按预发布使用；已知问题可在本仓库反馈。
