# BewlyCat Live 代码安全审查

审查日期：2026-10-27。范围为当前个人分支的扩展源码、权限、后台请求、页面通信、构建脚本、锁文件及本次构建产物。此文记录代码审查和依赖审计，不是杀毒引擎检测或绝对安全证明。

## 结论

在已检查的代码路径中，未发现植入病毒、挖矿、远程下载并执行脚本、键盘记录或向未知服务器发送账号凭据的行为。发现了已知依赖漏洞，并更新了直接处理页面 HTML 的 DOMPurify 和相关 Vue 依赖链。

生产依赖审计由 31 条告警降为 0 条。完整开发依赖审计仍有 155 条告警，其中包含 6 条 critical；告警数量按审计接口返回的 advisory 计算，不代表独立可利用攻击数量，也不代表这些包是恶意软件。

| 直播通信 | 聊天 WebSocket 校验 wss、B 站聊天域名和 /sub 路径；媒体地址限制为相关媒体 CDN；独立直播页的后台消息校验来源。 |

| 动态执行 | 扩展生产 CSP 的脚本来源为 self；项目源码未直接调用 eval、new Function，未发现远程脚本加载入口。产物仍包含依赖的 Function 构造分支，具体见下文，不能据源码搜索结果声称产物完全没有动态构造函数。innerHTML 的命中主要为打包图标、固定模板；接口内容的 HTML 渲染使用 DOMPurify。 |

## 依赖处理和剩余事项

- DOMPurify：3.2.6 → 3.4.17，保留原有调用方式。
- Vue：3.5.19 → 3.5.42，更新对应编译器与 renderer 依赖；锁文件同时更新 PostCSS、nanoid、source-map-js 的相容版本。
- 依赖更新禁用了安装脚本，不新增依赖种类；构建继续使用仓库已有配置。
- 开发工具链剩余的 critical 告警涉及 release-it 间接依赖 basic-ftp、tar，npm-run-all 间接依赖 shell-quote，以及 ESLint 插件间接引入的 Vitest/tinypool。是否可利用取决于对应工具和输入路径；本次未强制跨大版本升级全部开发工具，不将开发环境判定为已全面清理。
- 不能仅凭 devDependencies 分类断言不随扩展分发，例如 Vue 本身就用于浏览器。交付时另以构建生成的第三方模块清单与告警包名交叉检查。

- ESLint、Vue/TypeScript、Knip、样式编译及图标检查通过。
- 直播组件交互检查 53 项、播放源和资源释放检查 38 项、观看偏好检查 66 项、直播页面状态检查 62 项通过，共 219 项。

- 四个生产入口的第三方模块清单与完整审计中的受影响版本交叉核对，未命中未修复的已知漏洞。此核对不覆盖尚未公开的漏洞、未执行到的代码路径或整个构建工具链的安全性。
- 对安装包 10 个 JavaScript 文件进行语法树检查，直接 eval 调用未命中；Function 构造命中 4 处。3 处是依赖获取全局对象的兼容后备分支，1 处是 Vue 运行时模板编译器。项目组件使用预编译 render，没有发现远程输入被送入该模板编译器的链路；这些命中本身不构成恶意代码证据。Vue 编译器的冗余打包仍可进一步精简，本次没有放宽 CSP 来允许动态代码执行。

审计使用包注册表的漏洞查询接口，发送依赖名称和版本信息；没有向在线查毒服务上传源码、安装包、Cookie 或账号凭据。告警数据库和上游包可能变化，结论仅对应本次检查状态。

## 验证边界

未使用浏览器、临时 HTML 或复刻页面。播放器检查运行实际 Vue 组件逻辑与编译模板，媒体、指针和时钟使用内存适配器；这不能证明真实直播、浏览器事件时序和视觉效果已经实机验收。未检查用户电脑环境或其他来源的安装包，也未逐行审查每个第三方依赖的全部代码。
